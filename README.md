## ⚡ คำสั่งใช้งาน (Command Line)

### 1. สั่งสร้าง/อัปเดตเอกสารทั้งหมดแบบอัตโนมัติ
```bash
npm run build
```
*(ระบบจะประมวลผลไฟล์ Excel, PDF แยกฝ่าย, PDF รวมเล่ม, และอัปเดตสถิติทั้งหมดให้อัตโนมัติในครั้งเดียว)*

### 2. เริ่มต้นรันระบบเว็บค้นหา
```bash
npm start
```
